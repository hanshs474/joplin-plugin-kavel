# Kavel AI Image for Joplin

Kavel is a free AI video generator and AI image generator — 4K clips with sound, and images you can run without an account or a card. This plugin puts its image generator inside Joplin: select a line of text in a note, run **Kavel: image from selection**, and the finished image is inserted under it.

## Use

1. Select the text that describes the picture you want.
2. Right-click → **Kavel: image from selection**, or press the image button in the editor toolbar.
3. Wait about a minute. The image is added to the note as a markdown image.

No API key is needed to start: without one the plugin runs on [Kavel](https://www.kavel.ai/?utm_source=joplin&utm_medium=readme)'s free tier (a small daily allowance, watermarked images). To run on your account's credits, paste a key from [kavel.ai/settings/apikeys](https://www.kavel.ai/settings/apikeys) into **Tools → Options → Kavel AI Image**.

## Ideas

Planning a craft night or a seasonal post? Kavel's web tools go further than a plain prompt, for example its [AI pumpkin stencil generator](https://www.kavel.ai/image/ai-pumpkin-stencil-generator?utm_source=joplin&utm_medium=readme) turns a photo into a carvable stencil.

## Install

In Joplin: **Tools → Options → Plugins**, search for "Kavel".
